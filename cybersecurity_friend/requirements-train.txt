# QuantX — model training dependencies (PEFT / representation finetuning).
#
# Separate from requirements.txt on purpose: the serving image should not carry
# a multi-gigabyte training stack, and the training box needs packages the API
# server has no use for.
#
#   pip install -r requirements.txt -r requirements-train.txt
#
# ─────────────────────────────────────────────────────────────────────────────
# READ THIS BEFORE INSTALLING TORCH
# ─────────────────────────────────────────────────────────────────────────────
# `pip install torch` gives you a CPU-ONLY wheel. The machine this project moved
# from had exactly that — torch 2.9.1+cpu, torch.cuda.is_available() == False —
# which trains without error and simply takes a hundred times longer. It is a
# silent failure, not a loud one.
#
# On the GPU machine, install torch FIRST from the CUDA index, then install the
# rest of this file:
#
#   pip install torch==2.9.1 --index-url https://download.pytorch.org/whl/cu124
#
# Substitute the cu### tag matching the installed driver (`nvidia-smi`). Then
# verify before starting a run that could waste a day:
#
#   python -c "import torch; assert torch.cuda.is_available(), 'CPU-ONLY BUILD'; \
#              print(torch.cuda.get_device_name(0))"
#
# torch is deliberately NOT pinned below — pinning it here would let pip pull the
# CPU wheel over a correctly installed CUDA build.
# ─────────────────────────────────────────────────────────────────────────────
